Cliente Hubloc é uma empresa de locação de equipamentos (antiga Centralloc). O domínio do Google Workspace ainda é `@centralloc.com.br` apesar da mudança de nome para Hubloc.

**Why:** O nome "Hubloc" aparece no CRM e documentação, mas o workspace Google e domínio são `centralloc.com.br`. Essa distinção é importante para configuração de APIs do Google Workspace (Chat App, Auth, etc).

**How to apply:** Ao configurar integrações Google Workspace, usar domínio `@centralloc.com.br`. Na UI e documentação voltada ao cliente, usar "Hubloc".
